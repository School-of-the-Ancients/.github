# Contributing to School of the Ancients repositories

Start with the target repository's README, AGENTS.md, license, and rights notices.
Use the [repository map](https://github.com/School-of-the-Ancients/.github/blob/main/REPOSITORIES.md)
to distinguish current development from earlier prototypes. Discuss substantial
work before submitting it; use the relevant repository's issues and draft PRs.

## Permission and attribution

Identify copied or adapted code, dependencies, assets, model weights, papers, and
datasets by source, version, license, and required attribution. Confirm you have
authority to submit them under the agreed terms. Disclose AI-assisted work and
review it for copied material; do not guarantee exclusive rights in generated output.

The maintainer must settle contribution terms before merging third-party work.
Opening an issue, commenting, or submitting a PR is not a copyright assignment or
an unlimited grant of commercial relicensing rights. Existing licenses and any
applicable platform terms still apply. An additional agreement, if needed, must
be explicit and cannot retroactively take another contributor's rights.

Do not submit passwords, API keys, private learner records, identifiable room
captures, or confidential employer/client material. Use synthetic examples for
tests. Report security problems privately following SECURITY.md.

Keep unrelated behavior, saved data, historical license notices, and published
release artifacts unchanged. Include the relevant checks and an honest account
of limits in the PR; a build is not a headset or learning-outcome validation.
