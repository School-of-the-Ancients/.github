# Project map and source access

School of the Ancients is a working learning prototype. The public showcase is
[schooloftheancients.com](https://schooloftheancients.com/) and the project
introduction is in [profile/README.md](profile/README.md).

| Area | Purpose | Access |
| --- | --- | --- |
| School / Professor | Teachers, conversation, learning goals, practice, and learner records | Private implementation |
| Matrix | World creation, exhibits, interaction, saves, and desktop/AR/VR presentation | Private implementation |
| Earlier prototypes and research | Historical development, experiments, and source material | Private development records |
| Project website | Demo, public status, early-access updates | Public |
| Organization guidance | Contribution, security, support, and licensing information | Public |

Contact [the maintainer](https://github.com/thetopham) for collaboration or an
access request. Access is not automatic and does not itself grant a software
license, commercial rights, or permission to share private material.

Changing repository visibility does not revoke valid licenses granted for
previously distributed copies. See [LICENSING.md](LICENSING.md).
