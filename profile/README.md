# School of the Ancients

**Learn through conversation, experimentation, and reflection with historically inspired teachers.**

Start with a question, explore an explanation, make a prediction, and try an
interactive exhibit. Professor supports the learning conversation; Matrix
creates and presents the world. Free exploration remains available alongside
optional guided lessons.

## See the project

- [Website, project status, and early-access updates](https://schooloftheancients.com/)
- [Watch the Quest 3 demo](https://www.youtube.com/watch?v=zFG1tiifpe4)
- [Project areas and source access](../REPOSITORIES.md)
- [Collaboration and support](../SUPPORT.md)

This is a working prototype, not a public self-service hosted school. Device
support and reliability vary by build. Historical teachers are AI interpretations,
not authentic recordings or endorsements; generated explanations and exhibits
can need correction.
