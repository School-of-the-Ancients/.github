# School of the Ancients repository guidance

Start with the [public project overview](profile/README.md) and [repository map](REPOSITORIES.md).

This repository holds shared [contribution](CONTRIBUTING.md), [security](SECURITY.md),
and [support](SUPPORT.md) guidance. [Licensing policy](LICENSING.md) explains how
to read the different repositories' terms; it does not grant an organization-wide
software license. [Rights review](RIGHTS_REVIEW.md) records the unresolved work.

GitHub displays supported default community files where a repository does not
provide its own. Defaults do not become part of those repositories' downloads.
Each distribution must include its own applicable license and attribution.
